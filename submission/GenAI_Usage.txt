AI Used: ChatGPT

Prompt: generate a skeletal HTML structure for a website with 4 different pages. This website should be about a person. 
There should be a home page, a page for 3 of the person's hobbies, a page for 3 projects that person has completed, and 
a page for the person's resume. this should not be a complete website, but rather a barebones structure.


Initial Response:
Absolutely. Here’s a barebones 4-page HTML structure using a fictional person, Alex Johnson, as the example. There’s intentionally very little styling or content—just the structure you could build on later.
File structure
personal-website/
│
├── index.html
├── hobbies.html
├── projects.html
└── resume.html
index.html — Home Page
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Alex Johnson - Home</title>
</head>

<body>

    <header>
        <h1>Alex Johnson</h1>

        <nav>
            <a href="index.html">Home</a>
            <a href="hobbies.html">Hobbies</a>
            <a href="projects.html">Projects</a>
            <a href="resume.html">Resume</a>
        </nav>
    </header>

    <main>
        <section>
            <h2>Welcome</h2>
            <p>Welcome to Alex Johnson's personal website.</p>
        </section>

        <section>
            <h2>About Me</h2>
            <p>A brief introduction about Alex goes here.</p>
        </section>
    </main>

    <footer>
        <p>&copy; 2026 Alex Johnson</p>
    </footer>

</body>
</html>
